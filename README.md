# tonight!（イベント運営アプリ）

イベントごとに受付・バーカウンター・タイムテーブル／シフトを管理するクラウド同期アプリです。URLを知っている人はログインなしで同じデータを閲覧・編集できます。

## ディレクトリ構成

```text
├─ wrangler.jsonc
├─ src/worker.js
└─ public/
   ├─ index.html
   ├─ app.js
   ├─ style.css
   ├─ manifest.json
   ├─ sw.js
   ├─ TMPlogo.png
   ├─ icon-192.png
   └─ icon-512.png
```

## 今回の更新

- メンバー名簿で複数人を選択し、一括削除できる機能を追加。全員選択・選択人数表示に対応。削除したメンバーは全イベントの参加予定リストからも除外し、過去の受付・売上・出演履歴は保持。

- タイムテーブル／シフト画面への遷移時に、旧データや同期データの `acts`・`shifts` が欠けていても空配列として補完し、画面表示でエラーにならないよう修正。
- `wrangler.jsonc` のWorker名は既存環境との互換性を維持するため `tonight-system` に設定。

- メンバー名簿をCloudflare Durable Object側でも同期・保存するよう修正。名簿の追加・編集・削除・一括取込が複数端末に反映されるように変更。
- CSV／Excel取込時は名前・氏名に該当する列と学年列のみを抽出し、その他の列は取り込まないよう変更。CSVのカンマ・タブ・セミコロン区切りに対応。
- 受付履歴・バー販売履歴の復元状態を削除ログに保持し、同期時に古い削除状態で上書きされにくいよう修正。復元済みログは「復元済み」と表示。

- アプリ名を **tonight!** に統一。
- イベント一覧を月別のコンパクトなカードグリッドに変更。
- 各画面にページタイトルを表示し、イベントホームへ戻るショートカットを追加。
- イベント内の全画面で、出番・シフトの現在／次の予定をヘッダー直下に表示。20秒ごとに更新し、ライブ表示をゆっくり点滅。
- 出番・シフトは終了時刻が開始時刻より前の場合に登録不可。23:00〜翌1:00など、0〜5時台への日付またぎは登録可能。
- バーカウンターを簡易POSに変更。商品・価格を登録し、カート、数量変更、現金会計（預かり・お釣り）、ドリチケ会計を記録。
- 商品別に販売数、現金販売数、ドリチケ使用数、現金売上を集計。直近販売の取消にも対応。
- 既存の金庫開始／終了額の照合を維持し、POS現金売上との金額差を表示。
- 受付会計データの一括削除とバーカウンター会計データの一括削除を分離。イベント情報、出番／シフト、別会計の記録を誤って消さないよう確認文を変更。
- ボタンにホバー／タップ時の軽い弾み・拡大効果を追加。

## デプロイ

Cloudflare Workers & Pages で GitHub リポジトリを接続し、`wrangler.jsonc` の設定を使ってデプロイしてください。リポジトリのルートに `public/` と `src/` を置く構成です。

## 注意

- URLを知っている人は誰でも編集できます。共有範囲に注意してください。
- データは Cloudflare Durable Object に保存します。
- 古いバー記録は保持し、新しいPOS販売記録がある場合は新方式の集計を使います。
